## 과제 개요

대회에서 제시한 Mission 1은 신고자의 음성으로부터 제공된 성별 라벨을 분류하는 과제입니다.
평가 지표는 정확도(Accuracy)입니다.

## 데이터 구조

현재 로컬 `대학부 데이터/` 폴더에서 확인한 내용입니다.
대회 전체 데이터 수를 의미하지 않으며, 추가 다운로드 시 달라질 수 있습니다.

| 항목 | 확인 결과 |
|---|---:|
| WAV 파일 | 2,889개 |
| JSON 파일 | 1,871개 |
| 확장자를 제외한 파일명이 일치하는 WAV·JSON 쌍 | 346쌍 |
| JSON 읽기 오류 | 0개 |

- JSON의 최상위 항목은 모든 파일에서 동일한 17개입니다.
- `utterances`는 개별 발화 정보를 담은 목록입니다.
- 각 발화에는 `id`, `startAt`, `endAt`, `text`, `speaker`가 있습니다.
- 최상위 `endAt`은 20개 파일에서 실수형이고, 나머지 파일에서는 정수형입니다.
- `triage`는 19개 파일에서 빈 문자열입니다.
- 파일명 일치 여부만으로 데이터 누락을 단정할 수 없으므로 연결 관계를 추가 확인해야 합니다.

## 데이터 및 파일 관리

- 원본 WAV·JSON은 작업 코드와 분리하여 보관하고 원본을 수정하지 않습니다.
- 원본 데이터와 모델 파일은 GitHub에 업로드하지 않는 방침입니다.
- Google Drive 저장 위치는 업로드와 접근 확인 후 기록합니다.
- `.gitkeep`은 폴더를 기록하기 위한 빈 파일이며, 다른 파일의 업로드를 막지는 않습니다.
- 대용량 파일을 추가하기 전에 `.gitignore` 제외 설정과 `git status`를 확인합니다.
